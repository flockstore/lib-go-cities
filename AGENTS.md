# AGENTS

- All code must be performant.
- All exported functions, signatures, structs, struct properties, and interfaces must use Go doc style comments. Do not add comments inside code unless they clarify non-obvious behavior.
- All code must stay under 250 lines per file and a maximum of 6 file pairs per package. A source file and its test file count as one pair.
- All code must be reusable, async-capable, and fast.
- All code must follow Go style and avoid unnecessary overengineering.
